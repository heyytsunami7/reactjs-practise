# React.js Practice 🚀

> **"Code ownership over code copying."**

This repository documents my journey of learning and practicing **React.js** — from the fundamentals of components and state to routing, Context API, and Redux Toolkit.

The goal was never to simply collect tutorial projects. Each project was built to understand a specific React concept, practice implementing it, and gradually become more comfortable building applications without relying entirely on tutorials.

---

## 🎯 Purpose

This repository was created to:

* Understand React instead of memorizing it.
* Practice React concepts through small, focused projects.
* Build confidence by writing code repeatedly.
* Understand how different React features work together.
* Turn tutorial knowledge into practical development skills.
* Build a foundation for larger React applications and real-world projects.

## 🧠 Learning Philosophy

I followed a simple cycle:

1. Learn a concept.
2. Understand the architecture.
3. Read and understand the code.
4. Ask **"Why?"** instead of only **"How?"**
5. Rebuild with minimal peeking.
6. Modify or extend the project.
7. Repeat.

The goal was **code ownership, not code copying.**

---

## 🛠️ Practice Rules

While working through the projects, I tried to follow a few rules:

* Read and understand the code instead of blindly copying it.
* Ask questions whenever something feels like "magic."
* Keep components reusable.
* Prefer understanding over memorization.
* Experiment with the code after completing a feature.
* Break problems into smaller components.
* Write clean and readable code.
* Use each project as an opportunity to understand a specific React concept.
